# 石器时代

## 总体说明
1. 服务器端data兼容官方1.82-8.5的所有版本.
2. 服务器端兼容Windows或Linux编译, 目前采用x86_64位架构.
3. 客户端建议使用VS2022进行编译, 采用x86_32架构.


## 代码结构
client: 客户端源码.
client_lua: 客户端lua脚本.
server: 服务端源码.
server_lua: 服务端lua脚本.
db: 数据库配置文件


## 更新日志

2026.09.14 初步修复了不同玩家之间不可见, 不可组队的问题(后续持续测试).


### 本代码仅供学习使用

石器时代地图使用的是LS2DAT格式.
如果在Windows下编辑过文件，注意可能会有异常符号，导致文件无法加载.
