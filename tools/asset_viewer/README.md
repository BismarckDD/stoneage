# 石器时代素材浏览器

原生 Windows 素材预览工具，可按 ID 查看：

- `adrn*.bin + real*.bin` 中的图片
- `spradrn*.bin + spr*.bin` 中的宠物/人物造型动画
- `map/<ID>.dat` 地图总览

界面左侧通过“地图、宠物、人物、其他、图片”标签页分类列出实际存在的素材 ID，单击编号即可在右侧预览。顶部的 ID 输入框可用于快速跳转到指定编号。由于原始 Sprite 格式没有类别字段，人物按 `100000–100249`、宠物/生物按 `100250–109999` 的客户端编号惯例归类，其余 Sprite 放入“其他”。

程序会记住上次成功打开的客户端目录并在下次启动时自动加载。预览保持素材原始比例，大图仅在超出显示区时缩小，小型像素素材最多放大两倍。

## 使用

直接运行 `bin/StoneAgeAssetViewer.exe`，选择实际游戏客户端根目录。客户端目录需要包含 `data` 和 `map` 子目录。

图片 ID 是 `adrn` 图档编号；宠物/造型 ID 是 Sprite ID（可输入完整的 100000+ ID，也可以输入减去 100000 后的编号）；地图 ID 对应 `map/<ID>.dat`。

## 重新构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

需要安装 Visual Studio 的“使用 C++ 的桌面开发”组件。
